# Freeshots

Capture and annotate screenshots on your Mac. Your screenshots stay local—no accounts, uploads, or cloud sync.

- Capture an area, a window, or the entire screen.
- Add arrows, shapes, text, and freehand drawings.
- Hide sensitive details with redaction or pixelated blur.
- Customize backgrounds, padding, rounded corners, shadows, and device frames.
- Copy screenshots to the clipboard, save them as PNGs, or drag them into another app.

Requires macOS 26 or later.

## Install

```sh
brew install --cask l2fprod/tap/freeshots
```

Allow Screen Recording access when prompted to capture your screen.
