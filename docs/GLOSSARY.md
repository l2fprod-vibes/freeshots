# Freeshots glossary

| Term | Means | Not |
|---|---|---|
| Capture | A screenshot taken with Freeshots | recording, shot |
| Screenshot Name | The name used for the screenshot, its saved file, and the Floating Editor title | capture title |
| Capture Area | Start a drag selection for a screenshot | region grab |
| Capture Window | Select one visible app window for a screenshot | window grab |
| Include Window Shadow | Add the system shadow to a window capture | window shadow |
| Capture Display | Capture one selected display | full screen grab |
| Open Image | Open a local image in the Floating Editor | import screenshot |
| Open from Clipboard | Open a copied image in the Floating Editor | paste image |
| Screen Recording Permission | macOS access required to capture the screen | recording permission |
| Floating Editor | The panel that displays and marks up the current screenshot | viewer, editor window |
| Markup | Editable visual objects on a screenshot | annotations, doodles |
| Arrow | A directional mark on a screenshot | pointer |
| Arrow Style | The line and head appearance used for a new arrow | arrow type |
| Shape | A rectangle, oval, or line on a screenshot | object |
| Text | A label placed on a screenshot | callout |
| Pen | A freehand stroke on a screenshot | draw tool |
| Redact | Cover pixels so exported screenshots cannot reveal them | blur, hide |
| Blur | Obscure a rectangular screenshot area with pixelation | redact |
| Copy | Put the current screenshot on the clipboard | export |
| Save | Write the current screenshot as a local PNG file | export |
| Drag to Save | Create a local PNG by dragging the handle in the editor toolbar to a destination | drag out |
| Appearance | Controls for the screenshot backdrop, frame, ratio, and styling | inspector |
| Interface Appearance | Light or dark presentation of Freeshots windows, or the macOS appearance when set to System | screenshot appearance |
| Markup Color | Color used by new editable marks | ink |
| Remember Last Screenshot | Keep the latest capture locally for reopening | history |
| Start Freeshots at Login | Launch Freeshots automatically when the user logs in | launch on startup |
| Show Last Screenshot | Open the latest remembered capture in the Floating Editor | recent capture |
| Backdrop | Background, padding, corners, and shadow around a screenshot | template |
| Device Frame | Window, Mac, or phone frame around a screenshot | mockup |
| Aspect Ratio | Overall canvas shape, expanded around the screenshot without cropping it | crop |
| Custom Color | A color selected with the macOS color picker | custom ink |
| Padding | Clear or colored inset around a screenshot | margin |
| Screenshot Corners | Screenshot edge radius | screenshot rounding |
| Picture Corners | Overall picture edge radius | backdrop rounding |
| Shadow | Soft edge behind a screenshot | glow |
| Shadow Blur | Shadow softness amount | softness |
| Opacity | Shadow darkness amount | intensity |
| Reset Appearance | Restore default screenshot styling | clear |
| Fine Tune | Less frequently used spacing, corner, and shadow controls | advanced settings |
| Permission Check | Refresh the current macOS permission state | reauthorization |
| Skip for Now | Continue using Freeshots without granting Screen Recording Permission | grant permission |
