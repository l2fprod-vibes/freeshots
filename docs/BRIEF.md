# Freeshots

A private Mac capture utility for taking and marking up screenshots, then copying or saving the results locally. Quick screen recording is planned for v2.

## Replaces

Skitch for screenshot markup and the built-in capture flow for everyday screenshots. Monosnap is the reference for the planned v2 recording workflow.

## Main jobs

1. Capture an area, window, or display with a keyboard shortcut.
2. Optionally delay capture with a visible five-second countdown.
3. Review the capture in the Floating Editor, crop the screenshot itself, and add or adjust markup.
4. Copy recognized text from a screenshot using on-device text recognition.
5. Deliver the finished screenshot through clipboard copy, Save, or drag-to-file.

## Data

- Capture: screenshot image, timestamp, capture dimensions, and local file URL when saved.
- Markup: editable text, arrow, shape, freehand, and redaction objects attached to an image capture.
- Preferences: configurable capture shortcuts, local save defaults, optional launch at login, and System/Light/Dark interface appearance.
- About: app version and a locally bundled AI Badge image with source and license attribution.

## Shape

Menu bar utility with configurable global shortcuts and a floating capture/editor window. macOS 26 or later. Offline by design: no accounts, uploads, sync, analytics, telemetry, or network requests. Screenshots stay on the Mac. Copy, save, and drag-to-file are the delivery paths.

## System hooks

Global shortcuts, menu bar, clipboard, file save panel, and drag-and-drop file creation.

## Reference

Skitch for fast, approachable screenshot markup; Monosnap for the planned v2 recording workflow.

## Look

Own visual identity: modern, distinctive, and polished, while keeping Mac conventions for shortcuts, menus, clipboard, and drag-and-drop.

## Not in version one

- Cloud upload, share links, sync, accounts, analytics, and telemetry.
- Video recording (planned for v2).
- Capture history/library, search, and scrolling screenshots.
- Video editing and video audio/camera options.
